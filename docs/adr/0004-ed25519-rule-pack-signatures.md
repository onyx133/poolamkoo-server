# 0004. Ed25519 detached signatures, offline signing, server only verifies

Status: accepted

## Context

Rule packs tell the Android app how to parse bank SMS. A malicious or corrupted pack could cause wrong parsing or be a vehicle for abuse, so the app must only accept packs from the maintainer. The server and the transport (TLS, a reverse proxy, possibly a CDN or relay in future) must not be able to forge one, and a compromised server must not be able to push a bad pack.

## Decision

Packs are signed with Ed25519, producing a detached base64 signature over the exact pack bytes. The private key is generated by `rulepack:keygen` to a path outside the repository and used only on the release machine by `rulepack:sign`. The server never sees it.

The server holds only the public key (`RULEPACK_PUBLIC_KEY`, raw 32 bytes, base64). `rulepack:import` verifies the signature before storing, checks `formatVersion`, `version` and `minAppVersion`, refuses a version that is not greater than the stored maximum, and stores the bytes verbatim (`bytea`) with the signature. `GET /v1/rule-packs/latest` returns those bytes unchanged with `X-Signature` and `X-Rule-Pack-Version`. The app verifies with its embedded copy of the public key and ignores anything unsigned.

Ed25519 was chosen for small keys and signatures, deterministic signing, no parameter choices and first-class support in Node's `crypto` and on Android.

## Consequences

- Server compromise or a malicious CDN cannot create a pack the app will accept; it can only withhold or replay an older valid one (the app ignores versions not newer than its own).
- Verification at import is a guard against operator error, not the trust anchor. The trust anchor is the key pinned in the app.
- Key rotation requires an app release that ships the new public key, ideally accepting both for a transition. The plan is in the threat model.
- Because the signature covers raw bytes, nothing may re-serialise a pack (no JSON round-trip, no compression before signing).
- The release machine and its key backup become the critical asset to protect.
